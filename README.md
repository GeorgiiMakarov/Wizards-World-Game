# Wizards World Game 🆕 Новая игра

«Пиксельный маг» — PS1-фундамент коммерческого 3D-тайтла: ретро-3D экшен на Three.js (single-file).

## Что внутри
- 6 зон: Лунный посёлок, Шепчущая чаща, Пещера Стража, Кристальные копи, Снежные вершины, Парящие руины
- 4 жезла (клавиши 1–4): Жезл искры, Ледяной шар, Огненный посох, Громовой жезл
- Сумка-инвентарь (I): зелья, ягоды, свитки, щит
- 5 артефактов: Сапоги-скороходы, Перо феникса, Кольцо силы, Амулет жизни, Плащ тени
- Союзники (до 2 одновременно): Голем, Лучница, Фея Лили
- Лавка, рынок кристаллов, таверна «Лунный фонарь», календарь день/неделя
- Чиптюн, сейвы в localStorage, тач-управление

## Управление
← → бег · Пробел прыжок · Z удар · C сменить жезл · R предмет · Q применить · E говорить · I сумка

Жезлы: 1–4. Предмет можно менять тапом по панели вверху справа.

## Запуск
Открой `wizards-world-game.html` в браузере (нужен WebGL). Коснись, чтобы начать.
